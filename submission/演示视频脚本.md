# 城脉相机：演示视频脚本

建议主版90–120秒，MP4/H.264，1080p。官方若有不同限制，以官方为准。优先使用真实手机录屏；用桌面设备模拟时如实标注“手机尺寸演示”。

主线：荆州文旅场景 → 原片记忆护照 → 楚韵版式 → 真实出片保存 → 可选虚拟向往 → 上线与试点。

## 录制前

1. 打开 https://camera.jajaicb.cn/ ，刷新确认03「把荆州带回家」存在。
2. 开启勿扰、隐藏通知，录屏前不要显示账户/密钥/私人相册内容。
3. 准备一张获得公开展示许可的荆州照片。无法取得时用团队授权照片，避免暗示其拍摄地点已经系统核验；不要把自动化测试图当游客实拍。
4. 选一个容易讲的点位：古城墙/宾阳楼。
5. 输入心情：“和朋友一起，希望把荆州的故事带回家。”
6. 主流程只做一次真实文字生成；虚拟旅拍放第二段，非必需。已生成结果可以展示，但注明预先生成。
7. 准备PNG导出和手机文件/相册打开步骤。
8. 有配乐使用许可才配乐，旁白优先；不要为好听而默认公开使用未确认权利的音乐。

## 分镜与旁白

| 时间 | 画面 | 旁白 |
| --- | --- | --- |
| 0–10秒 | 标题＋荆州照片＋成品护照 | “一张旅行照片，能留下风景。我们还想让它多留下一点对荆州的理解。这是城脉相机。” |
| 10–25秒 | 打开正式网址、选择照片、选择宾阳楼、输入心情 | “选一张照片，确认这一站，再写下当下的心情。地点由用户选择，系统不把它当作到访认证。” |
| 25–40秒 | 选择城市记忆护照、楚韵；点击真实生成 | “AI根据地点资料和心情生成纪念文案。我们用城市记忆护照，把照片、文化发现和个人表达放在同一页。” |
| 40–65秒 | 出片、印章、心情、文化发现、下一站；收藏 | “记忆印章属于用户记录；下一站提供探索建议。印章册只在本机保存点位、类型和日期，不保存照片与心情。” |
| 65–80秒 | 同一结果切换素笺与楚韵，再导出、打开PNG | “楚韵版式采用原创凤鸟意象与漆红鎏金配色。切换版式无需再次调用模型，保存后就能把这份荆州记忆带走。” |
| 80–100秒（可选） | 展示本人授权的虚拟旅拍生成或明确标注预生成结果，向往印章 | “虚拟旅拍把人像和所选地点背景合成。它使用向往印章，明确不代表真实到访；人物和建筑细节仍需用户检查。” |
| 100–115秒 | 入口二维码＋两个版式成品＋试点文字 | “目前产品已经上线。下一步，我们希望在景点或民宿试点扫码纪念，用实际完成率和用户反馈验证它的价值。” |
| 115–120秒 | 城脉相机＋网址＋荆州奇旅 | “城脉相机，把荆州的故事带回家。” |

不希望做两分钟时：删除80–100秒旅拍段，剪成约90秒，不影响两项新创新展示。

## 真实性与剪辑

- 模型等待可加速或剪掉，但在画面标注“等待已加速，实际耗时X秒”。X必须来自本次记录。
- 不用模拟HTTP响应录屏冒充实时AI；若用既有生成图片，只作明确标注的效果补充。
- 至少保留：点击生成、结果出现、下载/保存、打开PNG。
- 不把“17点位”讲成17个景点均能旅拍；不是每个文化点位都有背景。
- 视频末尾写“扫码试点：下一步计划”，不把合作或效果写成已完成。

## 必备交付

- `城脉相机_演示视频.mp4`
- 一张与视频一致的PNG成品。
- 记录：设备/浏览器、实际生成耗时、保存结果、原始未剪辑录屏。

不要把源码、`.env`、私人人像、完整服务端日志放进公开视频。
