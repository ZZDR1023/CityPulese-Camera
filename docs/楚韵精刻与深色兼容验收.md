# 楚韵精刻版与深色兼容修复

## 修改范围

- 凤鸟：分层飞羽、羽轴刻线、冠羽、胸颈细纹、长尾卷草；亮金轮廓与低明度刻线分层，左右镜像。
- 顶角底板：暗铜漆色渐变、双层嵌线、裁切保护；矢量纹样不进入照片与标题。
- 下角城门：错缝砖石、压顶石、拱券径向分石、门栅、墙体刻线。
- 边框：三层细金线、回纹与菱形节点、连续水纹；随相纸高度重复铺排，不纵向拉伸。
- 保持矢量路径由 SVG 预览与 Canvas 导出共用，未增加图像文件网络依赖、模型调用、付费请求。
- 不修改照片、不改印章语义、不改额度；图像100次/小时、文字240次/小时保持原样，PPT不更新。

## 白底问题与处理

本轮真实复现：Chrome启用 `WebContentsForceDark` / `--force-dark-mode` 时，原内联SVG的深色凤鸟面板被浏览器反转为白色。仅设置 `prefers-color-scheme: dark` 不复现，问题不是项目自身切换了白色面板。

处理：

1. HTML头部加入 `color-scheme: only light` 元信息，根CSS同样声明 `color-scheme: only light`，明确这是已有配色的页面，不让浏览器启发式强制改色。
2. 相纸、SVG、照片、导出预览以局部规则保护作品色彩，声明 `forced-color-adjust: none`、`print-color-adjust: exact`。不在整个页面关闭系统高对比度控制。
3. 新增暗铜渐变面板；SVG与Canvas使用同一渐变坐标和停止点。
4. 头部渐变/裁切ID按相纸与护照区分，避免两种形式同时渲染时互相引用。

这不是新增整站深色UI：保持素笺/楚韵原有配色，系统深色下作品仍忠实显示。第三方浏览器私有夜间滤镜、扩展强行注入CSS或系统全屏反色不完全受网页控制，未声称覆盖所有厂商真机。
