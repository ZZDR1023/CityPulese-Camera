## 已纠正与避免混淆

- 荆州博物馆的“五代越王剑”不是“越王勾践剑”；不写后者由荆州博物馆收藏。
- 张居正故居、张居正墓园／纪念馆是不同点位；不把展示空间写成未经重建的明代原宅。
- 关帝庙不是关羽祠或关公义园；不重复未经独立核验的征战传说。
- 洈水与颜将军洞在官方松滋旅游线路中串联，但不推断它们统一售票或统一运营；不使用渭水、蒋渭水等错字检索结果。
- 金湾大道的洪湖湿地生态旅游区与瞿家湾的老街、生态游览区分开。Commons 搜出的深圳洪湖公园、静谧湖、武汉园博花车与航拍不作为洪湖旅拍背景。
- 郢城文化园2026年仍有官方文化线路和项目报道；这不代表园内熊猫乐园当前恢复开放。熊猫乐园卡仅保留历史介绍，页面和 PNG 都保留状态提醒。
- 不采用“最高／最大／唯一／最早／天下第一”、旧票价、免费开放、平台评分等未经本轮独立核验的强断言。

## 参考图核验方法与改进

1. 以必应查找正式名称和官方正文；官方网页只作为事实依据，不默认其图片允许再分发。
2. 通过 Commons API 读取原作品描述、作者、坐标、拍摄时间及许可；下载候选缩略图做 contact sheet，再看单图。只凭标题不通过核验。
3. 选择有真实步道、石板地或台阶可放人物的地面视角，尽量避开航拍、展品特写和遮挡。照片仍有历史年代与少量杂物，界面显示日期而不虚称最新空镜。
4. 每张 scene 增加中文 `placementHint` 和服务端英文 `compositionPrompt`，区分人物站位、安全边界、地标保留与光照；参考图预览改用 contain，避免先在 UI 裁掉塔顶或屋檐。
5. 未支持背景的地点选择虚拟旅拍时不会偷偷换成古城墙，须用户主动选择可旅拍景点。其他功能正常可用。

选图、署名及相同方式共享条件详见 [`public/scenes/ATTRIBUTION.md`](../public/scenes/ATTRIBUTION.md)。完整原始研究结果在本机忽略的 `artifacts/research/`，未公开上传未授权候选照片。

## 后续补图要求

仍需楚王车马阵、洈水、颜将军洞、洪湖湿地、瞿家湾、园博园、方特和郢城文化园的自摄／书面授权／明确开放许可实景。优先平视、有安全站立空间、地标明显、少路人的图片。取得图片后先看图核对点位，记录作者、来源、许可、修改与人物站位，再加入 scene 并重启、回归。
