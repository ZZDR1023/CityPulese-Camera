# 楚韵边框与邮戳美术优化

## 设计依据与范围

按用户提供的三张参考图：以第三张的整体边框为方向，以第二张的方形邮票式印章为方向。不直接使用参考图中的装饰像素、模型生成文字或水印，不把第三张重新绘制的古城/人物图拿来替换用户照片。

本轮仅本地制作与验收，未提交、推送或部署公网。此前记忆护照版公网仍正常运行。

## 已实现

1. **两种形式统一顶部**
   - 经典相纸、记忆护照共用“荆州 · 楚韵纪念”主标题。
   - 字体、字号、位置和配色一致；小副标题分别写“经典纪念相纸”“城市记忆护照”。
   - 页头保留英文小字、漆红渐变底与金色细分隔，避免两种形式文字长短导致视觉结构变化。

2. **对称四角与长页边框**
   - 左上/右上：原创羽翼凤鸟、卷草、弧形角框，右侧镜像。
   - 左下/右下：原创城墙砖缝、城垛与城门意象，强化古城属性。
   - 两侧：低对比连续细纹，底边：成组叠线波纹；双层金线收边。
   - 边框随相纸文字动态增高，花纹重复而不是纵向拉伸；下角永远锚定页尾。
   - 照片独立等比绘制，装饰不压到照片内；长照片不截去人物。
   - 预览胶带缩小、上移，不挡顶部主标题。

3. **第二张方向的邮票印章**
   - 将简单双线方框改为柔和齿孔边、双层内框、上下横线的方形邮票章。
   - 三行：荆州记忆/荆州向往、记忆邮戳/向往邮戳、点位短名。
   - 轻微旋转，保留右侧印章解释与既有到访边界。
   - 占用独立高度，不与“此刻的心情”重叠。自定义点位文本转义，不能注入SVG。

## 实现与字体

- `public/chu-artwork.js`：同一组原生矢量路径供SVG预览和Canvas导出使用，含凤鸟、城砖、边纹、邮票与页头。
- `public/paper-renderer.js`：楚韵照片宽1040 px、页头220 px、页底装饰区；仍为1200 px宽PNG。
- `public/fonts/citypulse-display.woff2`：约60 KB的本地展示字体子集，源自OFL授权Noto Serif CJK SC Regular，重新命名为CityPulse Display。
- `public/fonts/OFL.txt`：版权与OFL 1.1完整许可；不依赖线上字体CDN，也不分发本机微软字体。
- `scripts/subset-display-font.py`：开发期可复现子集脚本，运行时不需要Python/fonttools。

本轮不增加模型请求或费用、不恢复来源/署名/AI标签入口、不修改离线示例、景点资料或图像模型流程。
